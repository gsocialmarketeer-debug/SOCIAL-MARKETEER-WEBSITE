# Parker Plant & Machinery Website

This folder is a static backup/rebuild of the Parker Plant & Machinery website captured on 2026-07-29 and updated with expanded services, mini digger photos, a mini digger hire section and a blog/SEO section.

## Files

- `index.html` - main website page
- `styles.css` - website styling
- `assets/` - logo and website images

## Hosting

For Vercel static hosting, upload or commit the contents of this folder at the root of the GitHub repository. There is no build command required.

Important: only deploy this when you are ready for GitHub to become the source of the live website.
